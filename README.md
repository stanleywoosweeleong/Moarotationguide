# 虫药轮替 · Pest MoA

A bilingual (中文 / English), offline-capable PWA that helps Malaysian growers
rotate insecticides by IRAC mode-of-action group to slow resistance. Built from
Mr. Tee's *Bunting A* MoA rotation chart.

It has three tabs — **机制库 / MoA Library**, **轮替助手 / Rotation Helper**
(with a cross-resistance "Caution" tier and a built-in explainer), and
**调配顺序 / Tank-Mix Order** — plus a quick-lookup assistant.

---

## What's in the repo

| File | Role |
|------|------|
| `index.html` | **Served to users.** The built, self-contained page (React, CSS, JS, icons all inlined). **Do not hand-edit** — regenerated by the build. |
| `sw.js` | **Served to users.** Service worker for offline support. |
| `index.app.jsx` | **The source of truth — edit this.** The React app. |
| `rebuild.sh` | Build: compiles `index.app.jsx` -> `index.html`. |
| `precompile_jsx.py`, `inline_tw.py` | Build helpers (used by `rebuild.sh`). |
| `serve.sh` | Optional: serve locally for testing. |

Regenerated automatically, **not committed**: `node_modules/`, `package.json`,
`tailwind.config.js`, `input.css` (see `.gitignore`).

## Editing & rebuilding

1. Edit **`index.app.jsx`** (this is the app).
2. Rebuild:
   ```bash
   bash rebuild.sh index.html
   ```
   First run downloads the build tools (Tailwind, Babel, React) into
   `node_modules/` — one time, then it works offline. Needs Node.js + Python 3.
3. Commit the regenerated `index.html` (and `index.app.jsx`).

The build inlines Tailwind (only the classes you use), precompiles the JSX to
plain JS, and bundles React — so the result is one self-contained file with no
CDN dependencies. It preserves the `<head>` (title, icons, manifest, meta), so
those survive every rebuild.

## Deploying to GitHub Pages

Put **both** of these in the same folder of the Pages repo:

```
index.html
sw.js
```

That's it — all icons and the manifest are embedded inside `index.html`, so
there are **no icon files to add**. Keeping `index.app.jsx` and the build kit in
the same repo is harmless (Pages just stores them; users never load them) and
means you can always come back and edit.

> **`sw.js` must sit next to `index.html`** (same folder). A service worker can
> only control pages in its own folder and below.

## Offline support

- The app caches itself on first load and then works with **no connection** —
  Library, Rotation Helper, Tank-Mix, the explainer, language and font settings
  all run locally.
- **First visit must be online** (the worker can't cache what it's never seen).
- **Needs HTTPS** — GitHub Pages provides it. Opening the file from disk
  (`file://`) won't activate the worker.
- Page loads are **network-first**, so content updates reach users automatically
  when online; the cached copy is the fallback offline.
- The external MRL / DT50 links open other websites, so those still need a
  connection — the core app does not.
- To force every device to drop old caches after a big change, bump
  `CACHE_VERSION` at the top of `sw.js` (e.g. `pestmoa-v1` -> `pestmoa-v2`).
  Normal content updates don't need this.

## Data & safety

All chemical data is curated from Tee's *Bunting A* chart, cross-checked against
IRAC and peer-reviewed sources. Cross-resistance relationships and the MoA notes
are evidence-based. This is a **rotation guide, not a prescription** — always
check the product label, respect the pre-harvest interval, and never tank-mix
insecticides with glyphosate.
